# Provider marks

Small template (monochrome) marks used in Settings (sidebar, provider wells, account rows, empty states) and the popover header. Recreated as original geometry for a 12–16pt dark UI. Not copied from CDN artwork and not fetched at runtime.

Catalog imagesets live in `QuotaBar/Assets.xcassets/Brand*.imageset/` with `template-rendering-intent` so Theme tints apply.

| Asset | File | Mark | Notes |
| --- | --- | --- | --- |
| `BrandCursor` | `Cursor.svg` | North-west pointer | Cursor-style caret, not the marketing wordmark |
| `BrandChatGPT` | `ChatGPT.svg` | Six-petal blossom | Geometric OpenAI-style glyph |
| `BrandOpenCode` | `OpenCode.svg` | Prompt chevron | Terminal `>` for OpenCode Go |
| `BrandGLM` | `GLM.svg` | Hexagon + Z | Zhipu / z.ai hexagonal motif |
| `BrandGrok` | `Grok.svg` | X | xAI / Grok letterform |
